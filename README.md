# DPS Corpus

This repository contains the DPS-Corpus, a curated collection of Java source code examples demonstrating well-known software design patterns. The corpus is intended for use in research on software engineering, program analysis, and machine learning for code, and was developed for https://arxiv.org/abs/2504.11081

## Structure

The corpus is organized by author and design pattern. Each subdirectory contains one or more implementations of the following design patterns:

1. Abstract Factory
2. Adapter
3. Decorator
4. Facade
5. Factory
6. Observer
7. Memento
8. Singleton
9. Visitor

The code is collected from various open-source projects and educational resources. They are linked below:
